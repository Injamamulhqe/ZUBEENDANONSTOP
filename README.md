## 🎧 About

**ZUBEEN DA NONSTOP** is a cinematic Assamese nostalgia music website featuring a nonstop YouTube playlist dedicated to Zubeen Da.

> **His Voice • Our Emotions • Always**

## ✨ Features

- 🎶 YouTube nonstop playlist player
- ▶️ Play / Pause
- ⏮️ Previous / Next song
- 🔊 Mute / Unmute
- ⏱️ Clickable progress bar
- 🎵 Spotify search
- 🔴 YouTube Music search
- 🔎 Song search
- 📱 Responsive mobile design
- 🌌 Full-screen cinematic background
- 💎 Glassmorphism music player
